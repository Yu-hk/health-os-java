# Web 工作台

工作台位于 `src/main/resources/static/`，由 Spring Boot 同源托管。打包 JAR 和应用 Docker 镜像都包含前端，不需要额外启动 Node、Vite 或 Nginx。前端开发依赖只用于回归验证。

## 页面与流程

| 入口 | 支持的操作 |
| --- | --- |
| `/#/dashboard` | 当前环境的真实统计、业务入口、依赖状态；获取失败时明确显示未知 |
| `/#/patients` | 分页、当前页筛选、建档、指标、附件、版本、归档与恢复；跳转患者报告、问答、记忆和协同 |
| `/#/intake` | 上传、查看抽取进度、两道核查、人工补录、确认建档、生成评估报告 |
| `/#/care` | 按患者查看报告/计划、生成与编辑报告、签发、修订、计划生效、打卡、导出、审计 |
| `/#/classics` | 分页上传、流水线进度与重试、切片、证据、产物下载、图谱、带典籍上下文问答 |
| `/#/classics/:id/graph` | 实体关系图、键盘选择实体、1–3 跳邻域、原文证据表格；大图明确标注展示数量 |
| `/#/qa` | 同步问答、连续会话、异步运行、节点状态、命名 SSE 事件、重试/取消、患者知识库绑定 |
| `/#/memory` | 患者选择、初始化、记忆版本、随访、刷新、任务与导出 |
| `/#/agents` | 工具与角色目录、患者协同、运行与节点、重试/取消、MCP 握手和调用回执 |
| `/#/models` | 管理权限检查、未启用提示、配置编辑/探测、凭据替换/清除、版本历史和回滚 |
| `/#/traces` | 业务/状态筛选、分页、节点树、耗时和错误、事件与轨迹导出 |

主流程：资料录入 → 抽取完成 → 基础/临床核查 → 确认建档 → 生成报告 → 核对与签发 → 查看关联计划 → 确认生效 → 打卡。典籍流程：上传 → 解析完成 → 查看证据/图谱 → 进入带文档上下文的问答。

患者上下文通过 URL 查询参数传递，服务端仍按登录身份校验归属。表单提供已有记录的候选列表，较早的记录也可通过完整编号选择。列表筛选明确作用于当前页，上一页/下一页读取真实服务端分页。

## 与 health-os-simple 的对应

参考前端的分组导航、工作台、核查/签发流程，以及模型配置、Agent/MCP 和追踪工作空间，对接本工程实际的 `/api/v1` Java 契约。没有直接复制参考工程的 Python `/api/v2` 客户端，也没有引入参考项目的私有配置、运行数据或患者资料。

仅覆盖 Java 后端已有的能力；未移植参考工程的数据大屏、完整 RBAC 和其他尚无 Java 接口的模块。RAGFlow 接口桩仍是契约验证服务，不能用它的结果宣称真实 RAGFlow 检索已验收。

模型配置中心默认关闭，页面提供未启用提示。启用方法、主密钥和模型供应商配置见根 README 的模型路由章节。探测按钮会发起真实模型请求，浏览器验收不会自动点击它。

## 生命周期与错误处理

- 请求保留自定义幂等头，携带同源 Cookie，禁止缓存；包括下载在内的 401 会回到登录页。
- 请求使用两分钟超时预算；切换路由/退出会取消旧请求、轮询和 SSE。终态不继续轮询；请求失败后保留手动重试入口。
- 异步弹窗等待服务器结果，提交中禁止重复点击，失败保留输入并恢复按钮；支持必填校验、键盘焦点和 Escape。
- 操作编号仅使用安全随机源，不依赖 `randomUUID` 的安全上下文条件；不把患者资料、会话或模型密钥写入浏览器存储。
- 报告按真实的 `kind=report` 契约显示签发按钮；未生成完整的报告不提供签发，已签发文档通过修订流程编辑。

## 回归验证

需要 JDK 17、Maven、Node.js 22+；浏览器回归默认使用本机 Edge，可用 `HEALTHOS_BROWSER_CHANNEL=chrome` 切换到已安装的 Chrome。

```powershell
mvn verify
npm ci
npm run test:web
npm audit
```

浏览器回归必须指向本地隔离环境，不能使用真实业务数据库。先将最终 JAR 连接临时 PostgreSQL 启动在 `18101`，再执行：

```powershell
$env:HEALTHOS_BASE_URL = 'http://127.0.0.1:18101'
# 仅在临时数据库中允许创建合成资料/患者/报告：
$env:HEALTHOS_UI_TEST_ALLOW_WRITES = '1'
npm run test:web:browser
```

未设置 `HEALTHOS_UI_TEST_ALLOW_WRITES=1` 时，只检查登录、页面、移动导航和退出。脚本只接受 loopback 地址；账户可通过 `HEALTHOS_UI_USER` / `HEALTHOS_UI_PASSWORD` 指定，默认使用仓库演示账户。截图、结果和原始日志统一保存在被忽略的 `.local/frontend-check/`。

浏览器回归使用最终 JAR 提供的页面，覆盖资料上传/核查/建档、典籍解析与图谱、模板模型问答、报告签发、计划生效/打卡、MCP 回执与追踪详情。它不证明真实供应商模型、完整 RAGFlow、全部浏览器或公网部署环境已通过验证。
